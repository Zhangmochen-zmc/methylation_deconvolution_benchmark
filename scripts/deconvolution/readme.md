## deconvolution

This directory contains the method-specific configurations and execution instructions used for benchmarking each DNA methylation deconvolution method.

All methods were implemented as closely as possible to their original publications and software documentation to ensure reproducibility and fair comparison across methods.

Each method directory may include:

- Method-specific data preprocessing steps
- Marker selection procedures
- Deconvolution pipelines
- Inputs or resources specifically required by the corresponding method

Detailed running instructions and dependency information are provided within each method-specific subdirectory.
